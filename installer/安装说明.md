# MDpipe：安装与首次运行

## 这个安装包装了什么

| 内容 | 说明 |
|---|---|
| `scripts/` | 流水线本体（mdpipe、分析、出图、MM-PBSA、相互作用、体检） |
| `mdp_templates/` | 能量最小化 / NVT / NPT / 生产的 mdp 模板 |
| `pipeline/` | `config.json` 配置、`README.md`；`inbox/ jobs/ figures/ splits/` 空目录 |
| `tests/` | 单元测试（`python -m unittest discover -s tests`） |
| `skills/md-pipeline/` | 给 AI 助手用的操作技能：告诉 AI 怎么体检、投递、监控、分析、归档 |
| `docs/` | 操作手册、流程说明、本文件 |
| `启动图形界面.bat` / `mdpipe.bat` / `环境自检.bat` | 三个入口 |

安装程序的完整行为见下图（同目录 `pipeline\figures\installer_flow.png`，PDF 版同名）：

![安装包行为流程图](pipeline/figures/installer_flow.png)

**没有打包**：Python、GROMACS、WSL、AmberTools、PyMOL、LigPlot+。原因有两个：这些组件的许可证和体量不适合捆绑；而且装在哪里由机器决定，代装反而容易配错。安装完先跑「环境自检」，缺什么会逐项列出来，并给出安装办法。

哪些组件能自动装、哪些必须手动装，逐项写在同目录的《安装与环境清单》里，命令行也可以直接看：

```bash
mdpipe doctor --plan
```

## 让 AI 助手操作这套软件

安装包带了一份纯文本的 `skills/md-pipeline/SKILL.md`：命令地图、标准流程、输入要求、
判读标准和常见故障处置。它不会被执行，只是给 AI 读的说明书。

不同 AI 工具认不同的目录，所以安装器不替你选 Harness。`mdpipe skill --list` 会列出每个
目标的真实路径与检测结果，GUI 里「设置 → 安装 AI 技能…」可以勾选后一次装多个。

常见 Harness 的落点（本机实测存在以下技能库）：

| 目标名 | Harness | 落点 |
|---|---|---|
| `clawsgo` | ClawsGO 智能体 | `%USERPROFILE%\.clawsgo\skills\md-pipeline\SKILL.md` |
| `dsh` | DeepSeek Harness | `%USERPROFILE%\.dsh\skills\md-pipeline\SKILL.md` |
| `workbuddy` | WorkBuddy | `%USERPROFILE%\.workbuddy\skills\md-pipeline\SKILL.md` |
| `modao` | Modao（pi） | `%USERPROFILE%\.modao\agents\pi\skills\md-pipeline\SKILL.md` |
| `agentshome` | 通用 `~/.agents` | `%USERPROFILE%\.agents\skills\md-pipeline\SKILL.md` |
| `codex` | Codex CLI | `%USERPROFILE%\.codex\skills\md-pipeline\SKILL.md` |
| `claude` | Claude Code | `%USERPROFILE%\.claude\skills\md-pipeline\SKILL.md` |
| `project` / `pclaude` | 项目级 | `<项目>\.clawsgo\skills` / `<项目>\.claude\skills` |
| `trae` / `qoder` / `cursor` / `copilot` | 规则制 IDE | 项目内 `.trae\rules`、`.qoder\rules`、`.cursor\rules`、`.github\instructions` |
| `agents` | 通用智能体 | 项目 `AGENTS.md` 追加带标记段落 |

前七类是 skill 目录（一个文件夹 + `SKILL.md`），后四类是规则文件（写一段精简指引并指向
完整 `SKILL.md`）。用法：

```bash
mdpipe skill --list                          # 看每个目标：已装/未装、检测到没有、真实路径
mdpipe skill --target detected               # 只装到本机检测到的 Harness
mdpipe skill --target dsh workbuddy          # 指定几个
mdpipe skill --target trae qoder             # 往当前项目写规则文件
mdpipe skill --print                         # 打印全文，手动贴给任何 AI
```

没列到的工具也能用：把 `skills\md-pipeline\SKILL.md` 的路径告诉它，或把内容直接贴进对话。
所有安装都只是复制文本，不执行、不联网；卸载就是删掉对应的那个文件夹或标记段。

`AGENTS.md` 那一项只追加，带 `<!-- md-pipeline:begin -->` / `end` 标记，重复执行是幂等的；
文件里原有的内容不会被改动。用户目录里的安装只影响当前账户，撤销就是删掉那个 skill 文件夹。

装好后，直接说“把 receptor.pdb 和三个配体跑 100 ns”“看看这批轨迹的 RMSD”“算 MM-PBSA”，
AI 会先 `doctor` + `status`，再按技能里的流程调用 `mdpipe`。

遇到换力场、膜蛋白、共价配体、MM-PBSA 异常这类复杂问题时，技能会指引 AI 去查随附的
操作手册和安装清单，而不是凭记忆改参数：

```bash
mdpipe doc --list
mdpipe doc manual --section 16
mdpipe doc manual --grep "GROMOS" --context 2
```

安装目录里也留了一份技能文件（开始菜单「AI 操作说明（skill）」可直接看）。

## 前置条件

| 组件 | 要求 | 用途 |
|---|---|---|
| Python | 3.9+，安装时勾选 *Add python.exe to PATH* | 所有脚本 |
| numpy / scipy / matplotlib | `pip install numpy scipy matplotlib` | 必需 |
| GROMACS | 带 CUDA 的 Windows 版，`gmx.exe` | 跑 MD |
| NVIDIA 驱动 | 对应 `gmx --version` 里 CUDA 的要求 | GPU 加速 |
| WSL2 + Ubuntu | 仅 MM-PBSA / ATB 参数化需要 | 可选 |
| AmberTools / gmx_MMPBSA | conda 环境（手册 §14） | 可选 |
| PyMOL | `pip install pymol-open-source` | 结构图（可选） |
| LigPlot+ | 解压到 `<LigPlot+目录>` 或设 `LIGPLUS_HOME` | 2D 图（可选） |
| Ghostscript | 64 位版 | LigPlot+ 的 `.ps` 转图（可选） |
| RDKit | `pip install rdkit` | 2D 相互作用图（可选） |

## 安装

1. 双击 `MDpipe-Setup-1.7.exe`。
2. 安装到 `%LOCALAPPDATA%\MDpipe`，**不需要管理员权限**——流水线要在 `pipeline\jobs` 下写文件，装在 Program Files 会因权限失败。
3. 勾选「把 mdpipe 加入用户 PATH」后，可以在任意目录运行 `mdpipe doctor`、`mdpipe run`。
4. 安装完会自动打开「环境自检」：只读检测，不装任何东西，报告同时写到 `doctor_report.txt`。

静默安装（部署到多台机器）：

```bat
MDpipe-Setup-1.7.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TASKS="addpath"
```

## 第一次跑之前

1. 安装程序会自动运行 `mdpipe config --detect --write`，探测 GROMACS、WSL、AmberTools、gmx_MMPBSA、LigPlot+ 并写入 `pipeline\config.json`。没探测到的项可以手动填，或在界面「设置 → 自动探测组件路径」重试。
2. `mdpipe doctor` 全绿（`!` 可选缺失可以接受）再投作业。
3. 把蛋白/配体文件放进 `pipeline\inbox\`，`mdpipe scan` 自动登记，`mdpipe run` 开跑。

## 卸载

从「设置 → 应用」或开始菜单卸载。**默认保留 `pipeline\jobs`**——那是跑出来的轨迹和分析结果；确认不要了再手动删整个安装目录。

## 便携版

`MDpipe-portable.zip` 解压到任意可写目录即可，逻辑与安装版相同，只是没有开始菜单和卸载项。适合放在 U 盘或共享盘上。

## 自己重新打包

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1
powershell -ExecutionPolicy Bypass -File installer\build.ps1 -ZipOnly   # 只要便携版
```

需要 Inno Setup 6（`build.ps1` 会在常见路径里找 `ISCC.exe`，也可以用 `-Iscc` 指定）。
